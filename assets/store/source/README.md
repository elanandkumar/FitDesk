Solo Class HQ 1.5.0 phone screenshot compositions. It was created with the
built-in OpenAI image-generation tool on 2026-09-21, then combined with the
approved production icon, repository fonts, and real app captures by
`scripts/compose-store-screenshots.py`.

Generation prompt:

```text
Style/medium: polished minimal digital brand background, visually quiet, no illustration.

Color palette: #111018, #6D28D9, #6724F9, tiny restrained #F06432 accent.
Constraints: background only; no text, no letters, no logos, no icons, no devices, no UI, no people, no watermark; no busy patterns; no grain; no edge decorations that impair crop safety.
```
