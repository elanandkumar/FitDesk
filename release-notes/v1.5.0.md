# FitDesk v1.5.0

## Features

- Redesigned Income Summary with period selection, month-to-month comparisons, and interactive monthly charts.
- Added clearer paid and pending breakdowns for organizer payments and trainee packages.
- Added reusable currency, notes, and multi-select segmented controls.

## Improvements

- Improved payment filtering, sorting, summaries, and mark-paid workflows.
- Ending a class series now removes its upcoming sessions while preserving completed sessions and payment history.
- Standardized cards, form fields, badges, spacing, corner radii, and elevation throughout the app.
- Improved calendar selection styling, navigation density, accessibility labels, and responsive text layouts.
- Refreshed README screenshots and Play Store media.
